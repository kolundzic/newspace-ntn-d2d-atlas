# Glossary (Recnik pojmova)

| Term | Full English name | Serbian explanation |
|---|---|---|
| NTN | Non-Terrestrial Networks | Ne-zemaljske mreže integrisane u mobilne standarde (sateliti, HAPS) |
| D2D / DTC | Direct-to-Device / Direct-to-Cell | Direktna satelitska veza sa običnim telefonom bez specijalnog terminala |
| LEO | Low Earth Orbit | Niska orbita (stotine do ~2000 km) |
| MEO | Medium Earth Orbit | Srednja orbita (hiljade do ~20,000 km) |
| GEO | Geostationary Earth Orbit | Geostacionarna orbita (~35,786 km) |
| RTT | Round-Trip Time | Vreme odlaska i povratka signala; osnovna komponenta latencije |
| ISL | Inter-Satellite Link | Veza satelit–satelit (npr. laserska) |
| SSA | Space Situational Awareness | Praćenje objekata u orbiti radi procene rizika od sudara |
| CDM | Conjunction Data Message | Standardni format poruke o mogućem bliskom prolazu |
