# Failure Modes (Starter Set)

## 1. RF / link-layer failures
- insufficient uplink margin (handset constraints),
- interference and spectrum coordination issues,
- beam mis-pointing or scheduling contention.

## 2. Network/routing failures
- gateway congestion or outage,
- routing instabilities between terrestrial and space segments,
- control-plane mismatches in hybrid architectures.

## 3. Operational failures
- SSA process delays,
- incorrect ephemeris/timing distribution,
- degraded visibility predictions.

## 4. Generic mitigation patterns
- conservative assumptions and margins,
- graceful degradation (text-first, then data, then voice),
- continuous monitoring and postmortem discipline.
