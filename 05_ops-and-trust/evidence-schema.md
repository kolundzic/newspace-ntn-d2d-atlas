# Evidence Schema (Atlas Standard)

## 1. Goal
Define a minimal, repeatable structure for technical claims to keep content auditable.

## 2. Minimal evidence record
| Field | Meaning |
|---|---|
| claim_id | Stable identifier |
| claim | Short, testable statement |
| scope | Band/orbit/region/service constraints |
| assumptions | Inputs that must be true |
| method | Reference or computation |
| references | Primary sources |
| limitations | What is excluded |
| owner | Who stands behind the claim |

## 3. Usage
Early versions may use “starter references.” Mature versions should converge to primary sources and reproducible computations.
