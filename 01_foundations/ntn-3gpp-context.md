# 3GPP NTN Context (Non-Terrestrial Networks)

## 1. Definition
**NTN (Non-Terrestrial Networks)** integrates non-terrestrial platforms (satellites, HAPS) into mobile network architectures, notably within **3GPP** frameworks. Operationally, it aims to make non-terrestrial links behave as predictable components of end-to-end services.

## 2. Motivation
- terrestrial coverage gaps remain expensive,
- mobility markets are global (maritime/aviation/logistics),
- resilience and emergency communications benefit from infrastructure diversity.

## 3. NTN vs classical SatCom (conceptual)
| Dimension | Classical SatCom | 3GPP NTN |
|---|---|---|
| Integration | Separate ecosystem | Aligned with mobile architecture |
| Terminals | Specialized | Increasing focus on consumer devices (D2D) |
| Mobility | Often niche | Designed for mass mobility contexts |
| Roaming | Complex | Aims to reuse cellular roaming patterns |

## 4. Architectural appearances
NTN may function as:
- transport/backhaul,
- access network,
- hybrid integrated multi-layer network.
