# Inclination vs Altitude Trade-offs

## 1. Core variables
- altitude affects: slant range, path loss, footprint, visibility time,
- inclination affects: latitude coverage and revisit patterns.

## 2. Trade-space (qualitative)
| Choice | Advantages | Costs |
|---|---|---|
| Lower LEO | lower latency, lower FSPL | more satellites, more handoffs |
| Higher LEO | larger footprint, fewer satellites | higher latency, higher FSPL |
| High inclination | strong high-latitude/polar access | lower efficiency if equator-focused |
| Low inclination | efficient for selected latitude bands | weak polar access |

## 3. Practical note
Any trade-off discussion must state:
- user density assumptions,
- spectrum/band constraints,
- gateway economics,
- regulatory and sovereignty constraints.
