# Availability Models

## 1. Availability is probabilistic
For D2D, “coverage” should be expressed as:
- P(available now),
- expected time-to-available,
- expected session window length.

## 2. Typical inputs
- constellation geometry,
- elevation mask,
- user latitude,
- beam scheduling constraints,
- gateway/routing limitations.

## 3. Service mapping
- messaging: can tolerate intermittent windows,
- voice/data: require continuity and robust handoff handling.
