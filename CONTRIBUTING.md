# CONTRIBUTING (Academic / Evidence-First)

## Acceptance criteria
We accept material that is:
- **precise** (clear definitions; no ambiguity),
- **traceable** (assumptions + references),
- **operational** (notes failure modes and mitigations where relevant).

## Recommended chapter structure
1. Problem / Scope  
2. Definitions  
3. Assumptions (table)  
4. Model / Method  
5. Implications / Results  
6. Failure Modes and Mitigations  
7. References  

## Not accepted
- marketing claims without technical basis,
- numeric claims without context (band, EIRP, gains, masks, geometry),
- “magic numbers” without assumptions and references.
